C语言控制台计算器 - 使用说明书

一、项目概述

本项目是基于 C 语言开发的控制台计算器，具备累计计算、单次表达式计算、历史记录存储等核心功能，代码模块化设计，具备完善的异常处理机制，适合编程入门学习与练手。

二、核心功能

  • ✅ 累计计算模式：支持连续的加减乘除运算（如 0 + 5 - 2 * 3）
  • ✅ 单次表达式计算：直接输入完整表达式计算（如 8*9、10/2）
  • ✅ 历史记录管理：自动保存运算记录到本地文件，支持查看/清空
  • ✅ 异常处理：除数为0、非法输入、文件操作失败等场景容错
  • ✅ 跨平台兼容：支持 Windows/Linux/macOS 系统清屏操作

三、运行环境

  • 编译器：GCC / MinGW / MSVC（VS）/ Clion 等 C 语言编译器
  • 系统：Windows / Linux / macOS
  • 依赖：无第三方库，仅使用 C 标准库（stdio.h / stdlib.h）

四、使用教程

4.1 编译运行

方式1（命令行）：

// 编译 gcc calculator.c -o calculator // 运行（Windows） calculator.exe // 运行（Linux/macOS） ./calculator

方式2：直接用 VS/Clion 打开源码，点击「运行」按钮。

4.2 操作流程

  1. 运行程序后，显示主菜单，输入数字选择功能：
    • 1：进入累计计算模式
    • 2：进入单次表达式计算模式
    • 3：查看所有运算历史记录
    • 4：清空本地历史记录文件
    • 0：退出程序
  2. 累计计算模式：
    • 初始结果为 0，输入运算符（+ - * /）后按提示输入数字
    • 连续运算，输入 q/Q 退出并显示最终结果
  3. 单次计算模式：
    • 直接输入完整表达式（如 5+6、10/2），按回车自动计算
    • 支持 + - * / 四种运算符，自动判断除数为0异常

五、文件说明

  • calculator.c：主程序源码文件，包含所有功能实现
  • calculate_data.txt：运行后自动生成的历史记录文件，格式为「运算次数 运算符 操作数 结果」
  • README.md：项目说明文档（Markdown 版）
  • calculator_manual.html：本使用说明书（HTML 版）

六、异常处理说明

  • 除数为0：弹出错误提示，不执行运算
  • 非法运算符：提示输入无效，重新等待输入
  • 文件操作失败：通过 perror 打印错误信息，不影响核心运算
  • 非法菜单输入：过滤非数字输入，重新显示菜单

七、代码设计亮点

  • 模块化：按功能拆分函数（运算/文件/交互/菜单），职责单一
  • 命名规范：函数名见名知意（如 subtract/multiply/divide），避免关键字冲突
  • 性能优化：统一文件写入逻辑，避免频繁打开/关闭文件
  • 用户体验：输入缓冲区清空、跨平台清屏、友好的提示信息
