C 语言控制台计算器
C 语言课程设计 
项目介绍
一个基于 C 语言实现的控制台计算器，支持累计运算、单次表达式计算、历史记录持久化、异常处理。代码结构清晰、模块化、注释规范，适合作为编程入门练手项目。
功能清单
✅ 累计计算模式（连续 + - * /）
✅ 单次表达式计算（如 5+6、10*2）
✅ 历史记录本地文件存储（calculate_data.txt）
✅ 查看历史记录
✅ 清空历史记录
✅ 除数为 0 异常处理
✅ 文件操作异常判断
✅ 非法输入过滤与容错
✅ 跨平台清屏（Windows / Linux /macOS 通用）
技术点
C 语言基础语法、循环、分支
函数封装与模块化编程
指针操作（修改外部变量）
文件读写（追加、读取、清空）
输入输出处理与缓冲区清空
错误处理（perror、容错逻辑）
项目结构
plaintext
calculator/
├── calculator.c    # 主程序源码

运行说明
使用 VS / GCC / Clion 编译运行 calculator.c
按菜单提示操作：
1：累计计算
2：单次计算
3：查看历史
4：清空历史
0：退出
代码亮点
模块化设计功能按职责拆分：运算、文件操作、菜单逻辑、交互逻辑。
规范命名不使用无意义缩写，函数名见名知意：
add / subtract / multiply / divide
showHistory / clearHistory / writeRecord
健壮性
1.除数不能为 0
2.文件打开失败判断
3.非法运算符、非法菜单输入过滤
工程化习惯
1.统一文件写入，避免频繁开关文件
2.输入缓冲区清空，防止输入错乱
3.跨平台兼容写法
